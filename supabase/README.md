# WP5 Supabase Setup

1. Create a Supabase project.
2. Open the SQL editor and run `supabase/schema.sql`.
3. Create staff users in Supabase Auth.
4. Insert matching staff rows:

```sql
insert into staff_users (id, email, display_name, role)
values ('AUTH_USER_UUID', 'staff@example.com', 'Staff Name', 'super_admin');
```

5. Deploy the Edge Functions and set required secrets:

```sh
supabase functions deploy grade-english-literacy
supabase functions deploy manage-staff-user
supabase secrets set SUPABASE_SERVICE_ROLE_KEY=YOUR_SERVICE_ROLE_KEY
```

6. Copy the project URL and anon key into `assets/js/supabase-config.js`.
7. Open `login.html`, sign in with the Super Admin account, and manage staff access from Staff Management.

Student links must include an `assignment` query parameter generated by Test Admin. Direct links without an assignment token are rejected.

Staff permissions are feature based:

- `dashboard`
- `test_catalog`
- `generate_links`
- `view_results`
- `view_reports`
- `staff_management`
