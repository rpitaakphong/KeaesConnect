# Supabase Setup

Supabase provides staff authentication, staff permissions, assignment creation, student submissions, scoring storage, and admin result reporting for the Next.js app.

## Setup

1. Create or open the Supabase project.
2. Run `supabase/schema.sql` in the SQL editor.
3. Create staff users in Supabase Auth.
4. Insert matching staff rows:

```sql
insert into staff_users (id, email, display_name, role)
values ('AUTH_USER_UUID', 'staff@example.com', 'Staff Name', 'super_admin');
```

5. Deploy Edge Functions and set required secrets:

```sh
supabase functions deploy grade-english-literacy
supabase functions deploy manage-staff-user
supabase secrets set SUPABASE_SERVICE_ROLE_KEY=YOUR_SERVICE_ROLE_KEY
```

6. Set these environment variables in `apps/workspace-next/.env.local` and Netlify:

```sh
NEXT_PUBLIC_SUPABASE_URL=YOUR_PROJECT_URL
NEXT_PUBLIC_SUPABASE_ANON_KEY=YOUR_PUBLIC_ANON_KEY
```

7. Open `/login`, sign in as a Super Admin, and manage staff access from `/admin/staff`.

## Active Routes

Student links must be generated by Test Admin and include an `assignment` query parameter. Direct test links without an assignment token are rejected.

Seeded tests use Next routes such as `/tests/english-literacy-1/start`.

## Staff Permissions

- `dashboard`
- `test_catalog`
- `generate_links`
- `view_results`
- `view_reports`
- `hours_cross_check`
- `staff_management`
