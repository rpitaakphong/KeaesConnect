# Implementation Roadmap

Phase 0 Foundation: monorepo, Next.js, FastAPI, PostgreSQL, Redis, Docker Compose, auth foundation, RBAC foundation, audit logs, integration registry, design system.

Phase 1 Marketplace Core: learner registration/login, tutor application, tutor profile, admin tutor approval, tutor search, availability, booking quote, checkout, basic order/payment, meeting provider adapter, learner/tutor dashboards.

Phase 2 Money System: wallet accounts, ledger entries, commission rules, settlement records, withdrawal requests, admin withdrawal queue, refunds, financial audit log.

Phase 3 Course System: course creation, curriculum builder, protected video provider integration, enrollment, course progress, reviews.

Phase 4 Group Classes and Quizzes: group class creation, class package creation, group enrollment, quiz builder, quiz attempts, scoring/reporting.

Phase 5 CMS, SEO, Marketing: CMS pages, menus, FAQ, blog, testimonials, SEO metadata, redirects, sitemap, Google Analytics, Google Tag Manager, Mailchimp.

Phase 6 Growth and Global: referrals, affiliate module, multi-language content, Microsoft Translator helper, multi-currency, Fixer integration, additional payment providers, Thai payment adapter.

Phase 7 Premium Hardening: performance tuning, error tracking, provider health dashboards, admin exports, advanced reporting, 2FA for admins, security testing, load testing, backup/restore drills.
